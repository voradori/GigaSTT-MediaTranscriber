# Дорожная карта

Один короткий чеклист пользовательских возможностей. `[x]` — работает на реальном материале; `[ ]` — ещё не готово. Технические пробы и ограничения записываются в `SYSTEM.md`, не превращаются в отдельные задачи.

## 1. Автономная расшифровка

- [x] Установить Windows GigaSTT и модели; сохранить их локально вне Git.
- [x] Одним `transcribe.cmd` обработать пять OGG и большой MP3 из `input/` на CPU без Codex и Docker.
- [x] Для каждого файла сохранить исходный `raw.json`, нормализованный `transcript.json` и читаемый `transcript.txt`.
- [x] Пропускать готовые результаты без перезаписи; после ошибки позволять повторить файл.

## 2. Читаемость и спикеры

- [x] Подключить локальную модель пунктуации GigaSTT для новых файлов и переносить знаки в `transcript.txt` без изменения слов и таймкодов; проверить на OGG и полном MP3.
- [x] Отдельным проходом Community-1 добавить метки голосов к готовым словам без повторного STT; проверить первую часть YouTube-записи целиком на CUDA.
- [x] Обработать остальные четыре части первого плейлиста и 224 готовые расшифровки второго плейлиста без повторного STT.
- [ ] Прослушать характерные смены голосов и записи с четырьмя и более метками; подтвердить, что разметка помогает чтению. Метки обозначают голоса, не личности.

## 3. Видео и длинные записи

- [x] Извлечь AAC-дорожку из MP4 без перекодирования и изменения исходного видео; пройти полный файл 53:19.
- [x] Прогнать тот же большой MP4 через GigaSTT с CUDA и сравнить полное время с CPU-проходом около 105 с; практического выигрыша пока нет.

## 4. YouTube

- [x] Проверить одно видео из [тестового плейлиста](https://www.youtube.com/playlist?list=PLVfLJFEB_hPW-LROptgJsuMFxOUv1kRXW): получить аудио и расшифровать речь.
- [x] Затем прогнать весь плейлист как пакет с отдельным результатом на видео, без повторной загрузки уже готового.
- [x] Сделать отдельный `youtube.cmd`: пользователь вводит ссылку на видео или плейлист, утилита скачивает дорожки и расшифровывает без LLM. Плейлист получает свою папку в `input/` и `output/transcripts/`; внутри — ролики с названием и ID. Интернет нужен для скачивания, локальное распознавание — нет.
- [x] Сохранять разделение голосов отдельными файлами, оставляя обычный транскрипт неизменным и доступным независимо от качества меток.

- [x] Взять из стека `G:\MusicExtract` подход к извлечению аудио через `yt-dlp`, без музыкальных функций.

- [ ] По запросу создавать `summary.md` из готового транскрипта: свободные тезисы для брейншторма или протокол с решениями, вопросами и задачами.
- [ ] Отделять сказанное от выводов агента и не считать обсуждение автоматически принятым решением.

Выжимка не входит в автономный запуск. CPU-путь остаётся основным после сравнения с CUDA.
