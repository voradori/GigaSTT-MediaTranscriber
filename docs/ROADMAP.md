# Дорожная карта

Это план, а не описание уже работающей системы. Приоритет — удобный автономный запуск и сохраняемые результаты; точность моделей оценивается на реальных примерах без обещания безошибочной расшифровки.

## 1. Рабочая локальная расшифровка

Проверить доступность Docker Desktop, GPU и средств извлечения аудио. Запустить GigaSTT на одном коротком OGG и большом MP3. Сохранить полный исходный JSON и зафиксировать реальные время обработки, объём ресурсов и ограничения. Если Docker недоступен в рабочей среде, сначала установить точную причину, не подменяя результат предположением.

## 2. Автономный пользовательский вход

Один `.cmd` обрабатывает поддерживаемые файлы из `input/` и создаёт отдельную папку результата в `output/` для каждого файла. После первого получения образов и моделей повторный запуск должен работать без сети. Запуск поднимает нужные компоненты и завершает только принадлежащие задаче процессы; уже работавший Docker Desktop остаётся в прежнем состоянии. Повторная обработка не перезаписывает успешный результат молча.

## 3. Читаемый транскрипт и спикеры

Сохранять `raw.json`, формировать `transcript.json` и `transcript.txt` со строками `(0:01) Текст...`. Проверить встроенное разделение голосов GigaSTT на созвоне. Если оно мешает чтению, сравнить с отдельной локальной диаризацией; не вводить дополнительную модель без этой проверки. Ошибочные или неопределённые метки не превращать в имена участников.

## 4. Видео и длинные записи

Извлекать аудиодорожку из MP4 без изменения видео. Проверить полный проход большого файла, очистку временных данных, поведение при сбое и восстановление после повторного запуска. Сравнить результат с уже имеющимися MP3/WAV того же созвона.

## 5. Необязательная работа агента

Агент читает готовый транскрипт и создаёт `summary.md` по запросу: свободные смысловые тезисы для брейншторма или протокол с решениями, вопросами и задачами для рабочего мита. Выжимка должна отличаться от дословной расшифровки и не должна быть условием автономной работы `.cmd`.

## Критерий первого готового среза

Без участия LLM один запуск обрабатывает OGG и MP3 из `input/`, сохраняет сырой JSON и читаемый транскрипт по каждому файлу, не меняет оригиналы и не оставляет свои временные процессы запущенными. Видео, улучшенная диаризация и смысловая выжимка принимаются отдельно.
