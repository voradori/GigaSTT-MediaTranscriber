# Дорожная карта

Один файл для состояния мини-проекта. `[x]` означает проверенное на реальных записях; `[ ]` — ещё не проверено или не сделано. При завершении этапа отмечаем пункты и фиксируем его отдельным коммитом. Подробности проверки остаются в сообщении о коммите или результате работы, без отдельного трекера.

## 1. Автономная расшифровка

- [x] Установить Windows GigaSTT и модели; сохранить их локально вне Git.
- [x] Одним `transcribe.cmd` обработать пять OGG и большой MP3 из `input/` на CPU без Codex и Docker.
- [x] Для каждого файла сохранить исходный `raw.json`, нормализованный `transcript.json` и читаемый `transcript.txt`.
- [x] Пропускать уже готовые результаты без перезаписи; проверить повторным запуском.
- [ ] Проверить работу при физически отключённой сети после установки моделей.
- [ ] Проверить понятный сбой и безопасный повтор при повреждённом файле и прерывании обработки.

## 2. Читаемость и спикеры

- [x] Сравнить пять OGG с выводом внешнего STT: основное содержание сохранено, пунктуация и деление на фразы хуже.
- [x] Подключить локальную модель пунктуации GigaSTT для новых файлов и переносить знаки в `transcript.txt` без изменения слов и таймкодов; проверить на OGG и полном MP3.
- [ ] Доработать деление на смысловые фразы и проверить ошибочные знаки пунктуации на разных голосовых; прежние результаты не перезаписывать молча.
- [ ] Проверить встроенную диаризацию GigaSTT на реальном созвоне; метки обозначают голоса, не личности.
- [ ] Добавлять отдельную модель диаризации только если встроенная заметно мешает читать созвон.

## 3. Видео и длинные записи

- [x] Извлечь AAC-дорожку из MP4 без перекодирования и изменения исходного видео; пройти полный файл 53:19.
- [x] Удалить временно извлечённое аудио после успешного прохода.
- [x] Сравнить MP4 и MP3 одного созвона: содержание близко, длительность и таймкоды различаются.
- [ ] Проверить сбой и повтор на большом файле; сейчас повтор начинает распознавание заново.
- [ ] Проверить длительный сценарий 1–3 часа отдельно от 53-минутного примера.

## 4. Необязательная выжимка

- [ ] По запросу создавать `summary.md` из готового транскрипта: свободные тезисы для брейншторма или протокол с решениями, вопросами и задачами.
- [ ] Отделять сказанное от выводов агента и не считать обсуждение автоматически принятым решением.

Выжимка не входит в автономный запуск. Docker и GPU не требуются текущему Windows CLI; возвращаться к ним стоит только при конкретной потребности, выявленной проверкой.
